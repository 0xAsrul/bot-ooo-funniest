# The Funniest Out-of-Office

Entry for make.fun competition `u-kreutzx-the-funniest-out-of-office-054815cf`.

`main.py` writes a single line of out-of-office auto-reply text — 140
characters or fewer, one line, no links, no images — to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

The program is deterministic: it writes the same line on every run, uses no
randomness and no network.
